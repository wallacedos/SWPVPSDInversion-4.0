程序运行环境:
Matlab R2019a及以上。

第一步：将程序包放在matlab的当前文件夹，并加入路径。
第二步：依次运行Example文件夹下的rayleighTest_1.m、rayleighTest_2.m、loveTest.m、
rayleighFieldFundamentalDCInv.m、rayleighFieldMultimodalDCInv.m、XiongAnDCInv.m。
你会掌握基于预处理最速下降法的面波频散曲线反演程序包的使用方法。Example文件夹下的例子脚本
均包含较为丰富的注释。

建议使用该程序前，耐心阅读Doc文件夹下的PDF格式的反演方法及例子说明文档。
Doc文件夹下同时包含着演示教程视频。
